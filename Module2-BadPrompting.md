# BAD PROMPT — Invoice Thing

*Example of a poorly specified prompt covering the same three dimensions — look-and-feel, context management, and constraints/security/guardrails. Same intent, unusable result.*

---

## The Ask

Hey, can you help me build out something for invoices? We have a lot of issues in AP right now and I think AI could really help here. Basically invoices come in and someone has to check them and it takes forever. Can you make something that fixes that?

I've seen some cool demos of this kind of thing so you probably know what I'm going for. Use best practices.

## Look and Feel

Make it look good. Professional but modern. Clean.

It should be well formatted with headers and stuff. Maybe use tables where it makes sense? Or bullets, whatever works. Don't make it too long but also make sure it's comprehensive and covers everything.

Use your judgment on the structure. I trust you. Make it look like the kind of document an exec would be impressed by. It should feel enterprise-grade but also approachable, and technical but also readable by anyone.

Maybe add some visuals if you think it needs them.

## Context

It's for a finance team. Big company. There's a PO system and invoices come in from vendors and sometimes the numbers don't match, which causes problems. There's also the receiving side of it. You know how AP works.

Tolerances should be reasonable — use industry standard. Same for the approval thresholds, just pick normal numbers for a company our size. Currency isn't really a concern.

We might integrate with our ERP eventually. Or maybe OCR. Not sure yet, but build it so it's flexible. Actually maybe include OCR since most invoices come in as PDFs. Or don't, if that's too much. Your call.

Don't worry too much about scope, we can figure that out later. Just get something in front of people.

## Constraints and Security

Make sure it's secure and compliant. We're audited so keep that in mind.

Follow all relevant regulations. Don't do anything risky with the data. Obviously use good security practices — you know, encryption, access control, the usual. Make sure it can't be hacked.

Add guardrails so the AI doesn't do anything it shouldn't. It should be smart enough to know when to ask a human, but also we want this to be as automated as possible so it should handle most things on its own without slowing people down. Ideally it just approves the easy ones and only bothers us for the weird stuff, and it should be able to figure out which is which.

Use AI to determine whether the invoices match — that's the whole point of using AI, right?

Also it should be able to trigger the payment once everything checks out, to save a step. And email the vendor if something's wrong.

Feel free to use some of our real invoice data as examples so it feels realistic.

## What Good Looks Like

Just make it good. It should work and people should like it. Should be pretty accurate.

Let me know if you have questions, but ideally just run with it — I don't have a ton of time this week.

Thanks!
